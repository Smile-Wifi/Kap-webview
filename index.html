Before first use

  1. Push this project to a GitHub repository.
  2. Configure the required Vercel environment variables.
  3. Enable Actions and grant workflow write permission.
  4. Deploy this repository to Vercel.

Builds run on GitHub Actions. A successful request means queued/submitted—not that the APK has already compiled. Always install-test the resulting APK before distributing it.
